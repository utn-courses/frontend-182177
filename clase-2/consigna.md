# Actividad práctica: Página biográfica en HTML

## Consigna

Elegí una **persona real** que consideres interesante: un escritor, músico, científico, deportista, artista, inventor, actor, programador, etc.

Desarrollá una página web que presente su vida y trayectoria utilizando **únicamente HTML**. La página debe funcionar como una pequeña biografía web, organizada de manera clara y utilizando correctamente las posibilidades que ofrece HTML.

## Contenido de la página

La página deberá incluir:

- Una presentación inicial con el nombre completo y una introducción.
- Una imagen representativa de la persona.
- Información sobre su infancia y formación.
- Una sección sobre su trayectoria profesional.
- Sus principales obras, logros o aportes.
- Una cronología con acontecimientos importantes.
- Una sección de curiosidades.
- Una sección sobre su legado o influencia.
- Enlaces a las fuentes utilizadas para investigar.
- Un formulario relacionado con la persona elegida.

## Etiquetas a investigar

Además de las etiquetas trabajadas durante la clase, deberás **investigar y utilizar correctamente las siguientes etiquetas HTML**:

- `<details>`
- `<summary>`
- `<dialog>`
- `<time>`
- `<data>`
- `<abbr>`
- `<dfn>`
- `<q>`
- `<blockquote>`
- `<cite>`
- `<del>`
- `<ins>`
- `<mark>`
- `<meter>`
- `<progress>`
- `<output>`

### Uso correcto de las etiquetas

**No alcanza con colocar las etiquetas para cumplir el requisito.** Cada etiqueta debe utilizarse dentro de un **contexto en el que tenga sentido**.

Por ejemplo, si investigás `<time>`, deberás encontrar dentro de tu biografía información relacionada con fechas o períodos donde esa etiqueta sea apropiada. Si investigás `<mark>`, deberás utilizarla para destacar información relevante dentro de un contenido, y no simplemente colocarla alrededor de cualquier texto.

La elección de dónde utilizar cada etiqueta forma parte del ejercicio.

## Requisitos

La página deberá contener:

- Encabezado y navegación.
- Contenido principal dividido en secciones.
- Pie de página.
- Títulos de diferentes niveles.
- Párrafos.
- Listas ordenadas y/o desordenadas.
- Una o más imágenes con texto alternativo.
- Enlaces externos.
- Una tabla con información relacionada con el personaje.
- Un formulario.
- Las **16 etiquetas indicadas en la sección de investigación**.
- Comentarios HTML explicando brevemente qué hace cada una de las etiquetas investigadas.

Ejemplo:

```html
<!-- <time> se utiliza para representar una fecha o un período de tiempo -->
```

## Investigación

Podés consultar documentación, ejemplos y recursos disponibles en Internet para comprender cómo funciona cada etiqueta.

No es necesario que todas las etiquetas aparezcan juntas ni que sean utilizadas en una sección específica. **Distribuilas a lo largo de la página según el contenido y el significado que quieras representar.**

El objetivo es demostrar que comprendiste **para qué sirve cada elemento y cuándo corresponde utilizarlo**.

## Condiciones

- Utilizar únicamente HTML.
- No utilizar CSS.
- No utilizar JavaScript.
- Utilizar HTML semántico.
- No utilizar una etiqueta solamente para "cumplir" con la consigna.
- El contenido debe estar correctamente organizado.
- Las imágenes y enlaces deben funcionar.
- El código debe estar correctamente indentado.
- La información debe ser investigada y redactada con tus propias palabras.

## Desafío adicional

Investigá **3 etiquetas HTML que no aparezcan en esta consigna ni hayan sido explicadas en clase**.

Incorporá las tres a tu página y agregá un comentario explicando qué función cumplen y por qué decidiste utilizarlas en ese contexto.
