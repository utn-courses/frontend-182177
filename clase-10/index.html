CSS Motion Lab.

Transformaciones, transiciones y animaciones.

01

Transformaciones

Cambiamos la forma, posición o tamaño de un elemento.

M

translate()

Desplaza el elemento en los ejes X e Y.

transform: translate(20px, -10px);
S

scale()

Aumenta o reduce su tamaño.

transform: scale(1.2);
R

rotate()

Gira el elemento en grados.

transform: rotate(45deg);
K

skew()

Inclina el elemento sobre sus ejes.

transform: skew(15deg);
02

Transiciones

Hacemos que un cambio de estado sea progresivo.

C

transition: background

El color cambia suavemente al pasar el cursor.

transition: background 0.5s;
S

transition: transform

El tamaño cambia progresivamente.

transition: transform 0.5s;
M

transition: timing

Compará una transición lineal con una suave.

transition: transform 1s ease;

Transición en botones

Combinamos color, posición y sombra.

transition: all 0.3s ease;
03

Animaciones

Definimos una secuencia de cambios con @keyframes.

B

Rebote

El elemento sube y baja continuamente.

animation: bounce 1s infinite;
R

Rotación

Gira de forma automática.

animation: spin 2s linear infinite;
P

Pulso

Crece y se reduce repetidamente.

animation: pulse 1.5s infinite;
→

Desplazamiento

Se mueve entre diferentes posiciones.

animation: slide 2s infinite alternate;
